Beginner Guide

Cara pakai dump
  1. Pilih dump yang mau dipelajari, atau cari lewat search.
  2. Tekan View buat buka detailnya.
  3. Baca deskripsi dan bagian "About this Script".
  4. Baca kode dari atas ke bawah, pelan-pelan.
  5. Tekan Copy Code kalau mau dipindah ke lingkungan yang sesuai (misal Roblox Studio).
  6. Pelajari bagian yang belum ngerti, coba ubah angkanya dan lihat hasilnya.
  7. Kalau error, baca pesan errornya dan cek baris yang ditunjuk.

Roblox / Luau Basics

Apa itu Luau?

Bahasa pemrograman yang dipakai Roblox, turunan dari Lua dengan tambahan fitur.

Apa itu Roblox Studio?

Aplikasi resmi buat bikin game Roblox. Di sini kamu bikin map dan nulis script.

Apa itu Script, LocalScript, ModuleScript?

Script jalan di server. LocalScript jalan di perangkat pemain (UI, input, kamera). ModuleScript adalah kumpulan fungsi yang bisa dipakai ulang lewat require.

Apa itu Service?

Bagian bawaan Roblox yang punya fungsi khusus, diambil pakai game:GetService("Players").

Apa itu Variable, Function, Event?

Variable tempat nyimpen nilai (local x = 5). Function blok kode yang bisa dipanggil berulang. Event sinyal saat sesuatu terjadi, misalnya pemain masuk, lalu kamu sambungkan dengan :Connect(fungsi).

Apa itu RemoteEvent dan RemoteFunction?

Jembatan komunikasi client dan server. RemoteEvent kirim pesan satu arah. RemoteFunction kirim pertanyaan dan nunggu jawaban.

Common Errors

attempt to index nil

Kode mengakses sesuatu yang nil (tidak ketemu). Cek apakah object-nya ada, nama/path-nya benar, dan sudah ter-load (pakai WaitForChild).

X is not a valid member of Y

Nama child salah ketik atau belum ada. Cek Explorer di Studio dan pakai FindFirstChild.

Infinite yield possible

WaitForChild nunggu object yang tidak pernah muncul. Pastikan namanya benar.

attempt to call a nil value

Kamu memanggil fungsi yang tidak ada atau salah nama. Cek ejaan dan huruf besar-kecil.

Tips debugging umum

Pastikan kode tersalin lengkap, jalankan di lingkungan yang mendukung Luau, baca pesan error, dan pakai print() buat ngecek nilai.

How to Add a Dump

Semua data ada di array DUMPS di bagian bawah file ini (cari tulisan DUMP DATABASE). Salin salah satu blok, tempel di bawahnya, lalu ubah isinya. Kategori baru: tambahkan namanya di CATEGORIES.

{
  id: 9,                       // angka unik
  title: "Nama Dump",
  category: "Utilities",       // harus ada di CATEGORIES
  language: "Luau",
  description: "Deskripsi singkat.",
  tags: ["utility", "beginner"],
  code: `print("Hello Roblox")`,  // pakai backtick
  explanation: "Penjelasan fungsi kode.",
  note: "Catatan (opsional).",
  date: "2026-10-02"           // buat sort Newest/Oldest
},

View counter, favorites, dan recently viewed disimpan lokal di browser kamu (localStorage), bukan di server.
